      Drawer Navigation

      Slide-Out Panel · Side Menu Pattern

      功能说明

      抽屉菜单从屏幕边缘滑出，覆盖主内容区域。支持多级嵌套展开，手势滑动关闭。适用于导航层级较深、功能模块较多的应用场景。

      手势支持 多级嵌套 遮罩层

      实现要点

      1. 结构层

      由遮罩层(Overlay) + 面板(Panel)组成。遮罩层负责捕获点击关闭事件，面板承载菜单内容。

      2. 动画原理

      使用 transform: translateX() 实现硬件加速滑动，配合 cubic-bezier 缓动函数提供自然的手感。

      3. 多级展开

      通过 max-height 过渡实现子菜单的平滑展开/收起，避免使用 display:none 导致的动画中断。

      4. 手势关闭

      监听 touchstart / touchmove / touchend 事件，计算滑动距离与速度，超过阈值时触发关闭。

      Collapsible Panels · Expand/Collapse Pattern

      功能说明

      手风琴菜单通过点击标题展开/收起内容区域。支持单开模式(一次只展开一项)和多开模式，可无限层级嵌套。

      实现要点

      1. 高度动画

      使用 max-height 从 0 过渡到具体数值。由于无法预知内容高度，通常设置一个足够大的上限值(如 500px)，配合 overflow:hidden 实现裁剪效果。

      2. 单开模式实现

      展开某一项时，遍历同级所有项并强制收起。通过 classList.remove('open') 配合 CSS 过渡实现。

      3. 嵌套层级

      递归结构：每个 AccordionItem 内部可包含子 AccordionGroup。通过事件委托或独立事件绑定处理点击。

      Vertical Tabs ·

      节点 A 数据

      垂直标签页适用于左侧固定导航、右侧内容区的布局模式。常见于后台管理系统、设置页面等场景。

      节点 B 数据

      垂直布局在宽屏设备上效率更高，但在移动端通常需要折叠为水平布局或抽屉形式。

      节点 C 数据

      可通过媒体查询在移动端自动切换为水平标签，实现响应式适配。

      节点 D 数据

      垂直标签页支持图标+文字的组合形式，提升视觉辨识度。

      实现要点

      1. 状态管理

      维护 activeIndex 状态，切换时更新对应标签和面板的活动类名。避免直接操作 DOM，通过数据驱动视图更新。

      2. 指示器动画

      使用 getBoundingClientRect() 计算标签位置，通过 transform: translateX() 移动指示器元素，实现平滑跟随效果。

      3. 懒加载策略

      首次渲染仅加载当前标签内容，其他标签内容延迟渲染。可通过 IntersectionObserver 或手动标记实现。

      Floating Action Menu

      FAB · Speed Dial · Material Design Pattern

      功能说明

      悬浮操作按钮(FAB)位于屏幕固定位置，点击后展开 radial 或 linear 排列的子操作项。源自 Material Design 规范，是安卓原生系统的标志性交互。

      Material Design Radial Speed Dial
      点击右下角悬浮按钮体验 ·

      布局变体

      1. Linear (线性展开)

      子按钮沿垂直或水平方向线性排列。适合 2-5 个操作项，视觉层级清晰。

      2. Radial (径向展开)

      子按钮以主按钮为圆心呈扇形展开。适合 3-6 个操作项，空间利用率高但需避免遮挡内容。

      3. Morphing (变形展开)

      主按钮变形为工具栏或卡片，内部展示操作项。适合操作项较多(6+)的场景。

      实现要点

      1. 定位策略

      使用 position: fixed 固定定位，配合 z-index 确保层级正确。注意处理安全区域(safe-area-inset)。

      2. 展开动画

      子按钮使用 transition-delay 实现错开动画(Stagger Animation)，主按钮旋转 45° 变为关闭图标。

      3. 点击外部关闭

      监听 document 的点击事件，判断点击目标是否在 FAB 容器内，实现点击外部自动收起。

      实现要点

      1. 定位计算

      下拉菜单使用 position: absolute 相对于触发器定位。需检测视口边界，当下方空间不足时自动翻转至上方的 bottom: calc(100% + 4px)。

      2. 级联联动

      上级选择变化时，动态更新下级选项数据并重置下级选中状态。可通过事件总线或回调函数实现组件间通信。

      3. 键盘导航

      支持 ↑↓ 方向键导航、Enter 确认、Esc 关闭。通过 tabindex 和 keydown 事件监听实现无障碍访问。

      实现要点

      1. 状态机设计

      每个步骤具有三种状态：待处理(pending)、进行中(active)、已完成(completed)。通过状态机管理步骤流转逻辑。

      2. 线性约束

      默认线性流程不允许跳步，但可通过配置 linear: false 允许用户点击已完成的步骤进行回溯修改。

      3. 进度计算

      进度百分比 = (已完成步骤数 / 总步骤数) x 100%。可用于驱动顶部进度条或圆形进度指示器。

      Path Indicator · Hierarchy Navigation

      功能说明

      面包屑导航显示当前页面在网站层级结构中的位置，帮助用户了解所处位置并快速返回上级页面。适用于深层级内容结构。

      实现要点

      1. 数据结构

      面包屑数据通常以数组形式存储，每个元素包含 {label, path, icon}。通过 Array.prototype.slice(0, -1) 获取父级路径。

      2. 分隔符样式

      常见分隔符：> > / > >。也可使用图标字体或SVG箭头。最后一个元素通常为纯文本(当前页)，不可点击。

      3. Schema.org 标记

      使用语义化标签，配合 JSON-LD 的 BreadcrumbList 结构化数据提升 SEO。

      实现要点

      1. 事件监听

      PC端监听 contextmenu 事件并 preventDefault() 阻止默认菜单。移动端监听 touchstart 启动定时器，touchend 清除，超时触发。

      1. 三条线结构

      全屏菜单覆盖整个视口，提供沉浸式的导航体验。适合导航项较少(5-8个)但需要强视觉表现力的场景，如创意作品集、品牌官网。

      全屏覆盖 错开动画 高对比度

      实现要点

      1. 层级管理

      全屏菜单 z-index 应高于所有其他元素(通常 9999+)。打开时禁止背景滚动：document.body.style.overflow = 'hidden'。

      2. 错开动画

      菜单项使用 transition-delay 实现依次入场效果。延迟时间按索引递增(如 0.1s, 0.15s, 0.2s...)，创造节奏感。

      3. 关闭方式

      支持点击关闭按钮、点击背景遮罩、按 ESC 键三种关闭方式。关闭动画应与打开动画对称，保持视觉一致性。

      Radial Menu

      Pie Menu · Circular Menu · Fan Menu

      功能说明

      径向菜单以圆形扇区排列选项，用户向目标方向滑动即可选择。适合游戏UI、创意工具等需要快速选择的场景，在移动端较少使用。

      扇形排列 方向选择 游戏UI
      点击中心按钮展开径向菜单 ·

      实现要点

      1. 三角函数定位

      使用 Math.cos() 和 Math.sin() 计算每个选项的坐标：x = centerX + radius * cos(angle)，y = centerY + radius * sin(angle)。

      2. 展开动画

      选项从中心点向外扩散，使用 cubic-bezier(0.68, -0.55, 0.265, 1.55) 弹性缓动函数，创造"弹出"效果。

      3. 手势选择

      长按主按钮后向目标方向滑动释放即可选择。通过计算滑动角度匹配最近的选项，无需精确点击。

      Segmented Control

      iOS Segmented · Pill Switcher · Button Group

      功能说明

      分段控制器以一组互斥的按钮呈现选项，一次只能选中一项。源自 iOS 设计规范，适合 2-5 个选项的切换场景，如视图模式切换、时间范围选择。

      iOS风格 互斥选择 滑动指示器

      当前视图: 日

      按日粒度展示数据。分段控制器通过视觉上的"选中态"明确指示当前选项，减少用户的认知负担。

      实现要点

      1. 滑动指示器

      高级实现使用一个独立的指示器元素，通过 transform: translateX() 滑动到当前选中按钮位置。使用 getBoundingClientRect() 计算目标位置。

      2. 等宽分布

      使用 flex: 1 使所有分段按钮等宽分布。按钮文字使用 text-align: center 居中，确保视觉平衡。

      3. 禁用状态

      支持禁用(disabled)状态，禁用项降低透明度并移除点击事件。常用于数据加载中或权限不足的场景。
